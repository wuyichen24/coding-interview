# Detect Cycle

## Strategies
- Use hashset to remember which value has been seen.
- Use Floyd's cycle-finding algorithm.
   - Often provide better time complexity (*O(N)*)
- Check the graph can be topologically sorted or not (If a directed graph has an cycle, it can NOT be topologically sorted).
